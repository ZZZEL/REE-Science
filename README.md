## 1. 打开方式

**直接双击 `index.html`** 即可，无需安装、无需构建、无需启动服务、无需联网。

- 纯原生 HTML + CSS + JavaScript；**无 ES module**（`<script src=...>` 传统脚本）、**无 `fetch` / XHR**、无 CDN、无在线字体、无第三方 UI 框架、无图表库。
- 数据在 `assets/mock-data.js` 中以 `window.MOCK` 全局常量挂载，`assets/app.js` 同步执行注入界面，首屏导航无闪烁。
- 按 **1280px 最小宽度**设计，窄屏不要求适配（PRD 16.1 / 视觉基线 6.6）。
- 所有 AI / LLM 效果均为**预置 Mock 结构化结果**，不接任何真实模型、后端或外部服务。

> **数据声明**：本 Demo 全部工艺数值、指标、阈值、样本量、版本号、工单号均为
> **「示例数据，非真实工艺参数」**，仅用于界面占位与链路演示，不得用于生产、不得写成可指导生产的表述。
> v1.2 注脚收敛（验收 #7）：完整声明**每页页脚仅 1 处**；含数值数据卡以「示例数据」短角标标注（鼠标悬停显示完整声明，红线 #10 兜底）。

### 3.1 返回按钮统一规范（v1.4，黄总指令定稿）

1. **全局导航靠侧边栏**；「返回」按钮**只存在于带上下文的下钻流**，直接从侧边栏进入或直接打开 URL 时不渲染。
2. **统一位置与形态**：内容区顶部标题行（页面 h1 同一行），ghost 样式「← 返回 XX」，全站唯一形态、唯一位置。
3. **来源由 URL 显式传递**（`?from=<来源页>`）：
   - **v1.5（D-32）**：假设验证在批次 360 就地面板内完成；「带此结论返回建议单」→ `suggestion.html` 带 `from=batch` → 04 渲染「← 返回批次 360」（面板收起态保留 `view=verify` 以便返回时重新展开）；
   - 演示设置抽屉场景 / 导览直达 → 目标页带 `from=drawer` → **不渲染返回**（由侧边栏导航）；
   - `index.html?shift=next&verified=S-001` 回首页是业务流转不是返回，不适用。
4. **业务流转按钮保留原语义**：「核查这批」「带此结论返回建议单」「回到班次视图查看昨日结论」「执行」「回看建议单」等保留在对应结论卡 / 主卡内，不视为返回按钮。
5. **错误态统一入口**：所有错误态（02 / 03 / 04 入参缺失或不在示例数据）的「返回」统一为错误卡内唯一「回到班次视图」按钮、同一位置（`errorBoxHTML()`）。

**技术形态要点**：
- 跨页状态**以 URL query 为主路径**（T1–T4），`localStorage` 仅作增强，**不作为唯一路径**：

- `url(page, params)` 自动为每个内部链接附加 `role` / `stage`，保证影子态与角色跨页保持、上下文不丢失。
- 所有内部链接均为相对路径 + query；图标为内联 SVG 或纯 CSS；分组分布对比图为手写 inline SVG。

### 12.5 Tool 调用留痕与样品沉淀主链路

`一句话 → IntentProvider → 槽位 + ctx → 任务卡（人确认）→ Skill → Tool 只读登记 → evidence 挂 sample_id → 右栏定位`

- **确认门**：提交一句话只写入会话消息；`runToolsForTask()` 仅在 `task-execute` / `task-execute-confirm`（人工点击）后调用。未点执行，`UI.chatEvidence`、`MOCK`、业务状态零变化。
- **每次 Tool 调用一条 evidence**，字段：`evidence_id / tool_call_id / skill_id / sample_id / tool_id / action / input_summary / output_ref / source / truth_flag / ts / actor / intent`。
- **红线 #13**：数值类 Tool（T-02 检测报告读取、T-04 归因小模型）无 `sample_id` 时**不调用**，只写一条「已拦截」留痕并标 `n/a（未出数）`，界面给出告警；Demo 中 `chatCtx()` 总会回退到当前样品，链路不断。
- **兜底**：纯路由任务也写一条「页面路由，无 Tool 出数」留痕，保证每轮执行 ≥1 条挂 `sample_id` 的 evidence（自检 #5）。
- **回执卡**：会话流追加一张零工艺数值的留痕卡（条数 + 挂哪个样品 + Skill + source + truth_flag），出口指向样品中心时间轴。
- **沉淀不随对话删除**：「清空对话」只清 `UI.taskMessages`，已挂样品的 evidence 保留。
- `sim_query` / `unknown` 不产生 Tool 调用，因此不写留痕 —— 与确认门自洽，不虚增 evidence。
